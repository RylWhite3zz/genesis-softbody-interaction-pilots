# Original full-set reports

These files come directly from
`stage3_showcase_150_genesis_mpm_20260724/reports/` and retain the evidence for
all 150 generated assets. Some fields contain absolute paths from the original
workstation; those paths are archival metadata, not valid repository paths.

- `physical_parameter_assignment.json`: parameter distributions by geometry family and material profile.
- `physical_parameters.csv`: per-asset physical parameters.
- `showcase_mpm_status.json`: all Genesis MPM drop-run statuses.
- `showcase_urdf_validation_summary.json`: all URDF import statuses.
- Remaining JSON files: delivery and packaging summaries.
